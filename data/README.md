# data/

Pre-computed CSVs used by the `figures/` scripts (quick mode).
These files were generated by the corresponding `experiments/` scripts
and are included here so figures can be regenerated without running Stan.

## File index

### Multi-architecture capacity grid
Generated by `experiments/exp_multiarch_capacity.py`.

| File | Description | Size |
|------|-------------|------|
| `table_multiarch_def.csv` | Per-(arch, seed, flip_y) posterior descriptors, class_sep=1.0 | ~200 KB |
| `table_multiarch_def_yc.csv` | Same, with y_clean column (true labels) | ~200 KB |
| `table_multiarch_def_sep05.csv` | class_sep=0.5 variant | ~200 KB |
| `table_multiarch_def_sep1_W.csv` | class_sep=1.0, weak architectures | ~200 KB |
| `table_multiarch_def_sep2.csv` | class_sep=2.0 variant | ~200 KB |
| `table_multiarch_def_sep2_W.csv` | class_sep=2.0, weak architectures | ~200 KB |

| `sample_posteriors_yc.csv` | Same, with y_clean column | ~7 MB |
| `sample_posteriors_sep1_W.csv` | Per-sample posteriors, weak arch | ~5 MB |
| `sample_posteriors_sep2.csv` | Per-sample posteriors, class_sep=2.0 | ~5 MB |
